# TruthLoop

> **"Can you spot the scam?"** — A gamified misinformation literacy platform built for the UNESCO MIL Hackathon.

TruthLoop challenges users to identify real vs. fake claims, reveals their personal blind spots through AI analysis, and builds lasting media literacy through discussion.

---

## 🎯 Core Features

### 1. Claim Voting
Users browse a feed of pre-verified claims spanning breaking news, health, science, and politics. Each claim is presented without its verdict — the user votes **Real** or **Fake**, locks in their choice, and immediately sees the verified answer with source citations. One vote per claim, permanently recorded.

### 2. AI Scam Forecast
Every morning, Claude Sonnet generates a fresh **Scam Forecast** — predicting which categories of misinformation are likely to trend that day, why those scams work psychologically, and warning signs to watch for. Displayed as a daily card on the home screen.

### 3. Personalized Blind-Spot Report
The product's key differentiator. After a week of voting, each user receives a **Weekly Blind-Spot Report** generated by Claude Opus — analyzing their voting history to identify the *specific types* of scams that consistently fool them, and explaining *why* those particular scams work on people like them. Not generic media literacy tips — deeply personal analysis.

### 4. Discussion Threads
Every claim has a Reddit-style nested comment thread. Users can debate the verdict, share supporting sources, and flag bad-faith arguments. AI (Claude Sonnet) provides toxicity moderation on comments.

### 5. Gamification
- **Points** — earned per vote, comment, and report
- **8 Badges** — First Vote, Skeptic, Debunker, Truth Seeker, Iron Eye, Overconfident, Consistent, and Legend
- **Daily Leaderboard** — resets at UTC midnight; top scorer of the day gets featured
- **All-Time Leaderboard** — lifetime points ranking

### 6. Email Alerts (via Resend)
Users configure alert preferences:
- **Weekly digest** — summary of their voting activity and blind-spot trend
- **Instant alerts** — high-severity misinformation targeting their demographics

## 🔬 How It Works

```
User signs in with Google OAuth
        │
        ▼
Browse pre-verified claims (origin: manual + hourly harvester)
        │
        ▼
Vote Real / Fake → vote locked → verdict revealed with citations
        │
        ├─── Points awarded
        ├─── Comment thread opens
        └─── Vote recorded in history
        │
        ▼
After 7 days → Weekly Blind-Spot Report generated by Claude Opus
        │
        ▼
Daily Scam Forecast card refreshed each morning (Claude Sonnet)
```

## 🏗️ Architecture

| Layer | Details |
|---|---|
| **Frontend** | React 19, Vite 6, Tailwind v4, shadcn/ui, TanStack Query, React Router 6 |
| **Backend** | Express, TypeScript, PostgreSQL (pg), Passport (Google OAuth) |
| **AI** | Claude Sonnet 4.5 (forecasts, comments), Claude Opus 4.1 (blind-spot reports) |
| **Email** | Resend + React Email |
| **Real-time** | Server-Sent Events (SSE) for live leaderboard updates |
